# Omarchy tweaks — Matviy

Відтворюваний набір локальних налаштувань Omarchy з цієї системи. Потрібна версія Omarchy з Lua-конфігурацією Hyprland і Quickshell. Це набір користувацьких конфігурацій, а не повна копія ОС.

## Встановлення

```bash
git clone https://github.com/TaZ1kS/omarchy-tweaks.git
cd omarchy-tweaks
./install.sh --dry-run
./install.sh
```

Скрипт замінює перелічені конфігурації на профіль з репозиторію (зокрема клавіші, введення, оформлення, розкладку топбару й Fish). Перед кожною заміною зберігає попередній файл. Нові файли теж записуються в журнал, щоб відновлення могло їх прибрати. Пакети автоматично не встановлюються. Запуск від звичайного користувача, без sudo.

Резервні копії: `~/.local/state/omarchy-tweaks/backups/`. Наприкінці встановлення скрипт показує точну команду відновлення:

```bash
python3 install.py --restore ~/.local/state/omarchy-tweaks/backups/НАЗВА_КОПІЇ
```

Після відновлення вийдіть із сеансу й увійдіть знову. Для встановлення скрипт намагається перезавантажити конфігурацію Hyprland та плагіни. Якщо живий зв’язок недоступний, також потрібен повторний вхід.

## Що включено

- Блюр у межах pop-up, прозорість карток 35%, прозорий фон навколо меню.
- Локальна копія OSD для гучності, яскравості та станів телефонного екрана.
- Системний монітор у топбарі: CPU, RAM, GPU, диск, мережа, температура CPU package, графік з часовою історією, інтервал 250 мс, налаштування розмірів і процесів, пауза та сортування.
- CPU процесів показується як середнє за час роботи, список процесів оновлюється раз на 2 секунди. Диск і NVIDIA опитуються рідше, ніж основні показники.
- Клавіші буфера обміну, емодзі, скриншота, Recall, Telegram, Discord і телефону.
- Відкладене перемикання робочих просторів коліщатком MX Master; українська/англійська розкладки.
- `recall`, `phone-screen`, `setup-headless.sh`, `yoga-autorotate`, `zen-browser-100`, `omarchy-logo-gradient` і обгортка `superwhisper`.
- Fish aliases і генерація кольорів Fish/OpenCode з теми Omarchy, hooks синхронізації теми.

Телефонний екран та поворот Yoga додаються до автозапуску як у вихідному профілі. Налаштування вводу містять прив’язку сенсорного екрана до HEADLESS-1. Перегляньте `payload/.config/hypr/` перед встановленням на іншому обладнанні.

## Обладнання та залежності

```bash
./install.sh --hardware
```

Ця опція додатково копіює вихідну розкладку трьох фізичних моніторів і HEADLESS-1 та unit Sunshine; службу не вмикає. Без опції наявний `monitors.lua` зберігається. На чистій системі створюється автоматична розкладка.

Основні залежності: Omarchy, Quickshell, Hyprland, Bash, Python 3.11+, procps-ng, coreutils, jq; `btop` для відкриття повного диспетчера. Окремі можливості потребують `wayvnc`, `android-tools`, Sunshine/Moonlight, `iio-sensor-proxy`, Fish, eza, socat, Zen Browser, Superwhisper, materialgram, vesktop і GridCraft. Встановлюйте лише потрібні можливості через пакетний менеджер. Скрипт `phone-screen tweaks` містить окремі дії для rooted Android — встановлення їх не запускає.

Виключено ключі, облікові дані, історію, кеші, резервні копії, браузерні профілі, Sunshine pairing та стан програм. Сторонні плагіни/програми, встановлені пакунками, залишаються зовнішніми залежностями. У копії OSD збережено код Omarchy; його походження: `/usr/share/omarchy/shell/plugins/osd/`.
